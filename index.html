Importar dados

Tudo é lido no seu navegador. Nada é enviado a servidor e os dados ficam salvos só neste navegador.

Fontes de dados

Arraste um .xlsx ou .csv aquiou clique para escolher. Um .xlsx pode ter uma aba de colaboradores e outra de salas.

Adicionar uma API

Aceita JSON (lista ou objeto com a lista) e CSV, com paginação por next_page_url. Os campos são reconhecidos como as colunas da planilha, também em inglês. A API precisa liberar CORS para o navegador; o token fica salvo só neste navegador.

Colaboradores (Departamento e Admissão são obrigatórios)

Nome;Departamento;Cargo;Salário;Admissão;Demissão;Faltas;Horas Extras;Sexo Ana Souza;Produção;Operador;2850,00;12/03/2023;;1;10;F Carlos Lima;Logística;Auxiliar;2400,00;05/08/2021;30/06/2026;0;0;M

Salas de reunião (Sala e Início são obrigatórios)

Sala;Capacidade;Data;Início;Fim;Assunto;Responsável;Participantes Sala Executiva;10;26/10/2026;09:00;10:00;Alinhamento do DP;Marina;6

Faltas e Horas Extras são os valores do mês atual de cada pessoa. Demissão em branco significa colaborador ativo. A Data das salas é opcional.

Texto para configurar a API do outro sistema

Envie este texto ao time (ou à IA) que cuida do sistema de origem. Ele descreve os dois endereços, os campos, o formato e as regras de acesso.

Configurar escritório

Andares, salas e bonecos. As escolhas ficam salvas neste navegador e valem mesmo quando você importa uma planilha nova.
